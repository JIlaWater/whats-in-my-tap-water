# AGENTS Instructions

- Never invent water data or present fabricated local measurements.
- Every non-sample water datapoint must include source metadata and dates.
- Always include confidence, coverage, and freshness labels when showing water data.
- Build mobile-first, accessible UI patterns with clear contrast and semantics.
- Keep TypeScript strict and avoid unsafe `any`.
- Keep SEO-safe defaults: thin/low-confidence pages should be `noindex`.
- Do not commit tracking or webhook secrets in source; use environment variables.
