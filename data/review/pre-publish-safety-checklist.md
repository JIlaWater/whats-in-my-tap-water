# Pre-publish safety checklist (Brisbane/SEQ)

Use this checklist after import + review validation and before any row can move to `publishable`.

## Required checks (must all be YES)
- [ ] Source URL exists for each candidate row.
- [ ] Publication date exists for each candidate row.
- [ ] Last checked date exists for each candidate row.
- [ ] Value and unit have been checked against the official source.
- [ ] Coverage level is confirmed (`suburb`, `postcode`, `supply_zone`, `authority`, `council`, or `state`).
- [ ] Confidence level is confirmed and justified.
- [ ] No low-confidence rows are marked `publishable`.
- [ ] Human reviewer has signed off (initials + date recorded).
- [ ] Beta warning removal is **not allowed** until enough records are published safely.
